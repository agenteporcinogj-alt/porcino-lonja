Cuánto vale acertar

~66.000 € / semana

Es lo que vale cada céntimo/kg para Grupo Jorge: 55.000 cerdos × 120 kg. Al año, cada céntimo son ~3,3 millones €. Por eso afinar cuándo vender pesa tanto — y por eso este modelo tiene sentido.
